An original open-world courier crime game, built for [make.fun's "Make GTA 6" bounty](https://make.fun/bounty/gta6-01).

Moonrise City is a waterfront supercity — Dubai-meets-Miami towers along a bay — that plays from daytime into a signature moonrise, the huge bright moon high over the skyline. You are a courier building a name from nothing: run Zara Vale's five-mission story, steal from a fleet of luxury cars, dodge or outrun the MCPD under a five-star wanted system, and keep the money coming in with free-roam jobs after the story ends.

**In the game:** a seeded 3600×2600 city with around 150 towers and five landmarks, on-foot and arcade driving, traffic AI, around 20 stealable cars, a witness-and-report wanted system, police interceptors that pursue, ram and arrest, BUSTED and WASTED outcomes, punches and a sidearm, a full HUD with live minimap, a day cycle into moonrise, synthesized audio, and a local save with Continue.

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a browser. The game is static files under `game/` — no build step, no network requests.
